## 1. 최종 확정 방향과 완료 범위

이번 단계에서 도형 랙돌의 신체·관절 구성, 잡기·던지기·각운동, 자기 충돌·방 경계, 시간 후 관절 정렬, 자동 기립의 기본 동작과 수치를 확정했다. 웹페이지에는 확정 수치와 각운동 설명을 실험 노트로 표시한다. 기초 물리 설계는 여기서 마무리하고, 이후 기능은 이 구현을 기반으로 확장한다.

사용자는 두 가지 관절 복구 방식을 비교한 뒤 2026-11-08에 2번을 개발 기준으로 선택했다. `DEFAULT_SETTINGS.experiment`는 `2`이다. 웹페이지의 복구 방식 선택 메뉴는 제거했으며, 1번 코드는 내부 비교용으로만 유지한다.

| --- | --- | --- |

**관절 정렬과 기립은 별도 동작이다.** 관절 정렬은 조작 종료 2초 뒤 움직이는 중에도 실행한다. 정렬 완료 이후 기존 안정 조건 또는 최대 부위 선속력 50px/s 이하 조건이 2초 이어지면 기립한다.

### 완료까지 반영한 최종 조정

- 밀치기 입력·효과·단축키·강도 설정을 삭제했다. 잡기·흔들기·던지기로 충돌을 만든다.
- 던지기 50%, 중력 2.5배, 관절 정렬 대기 2초, 관절 지연 0%, 기립 대기 2초를 확정했다. 화면에서는 값만 표시하며, `FIXED_SETTINGS`를 설정 적용 시에도 덮어써 고정한다.
- 탄성은 95%로 고정하고 조절 바를 제거했다. 관절 복구 방식 선택 메뉴도 제거해 웹페이지에서는 채택한 2번을 사용한다.
- 잡은 부위를 정적으로 만들고 각도를 덮어쓰는 방식을 제거했다. 클릭 지점의 로컬 좌표를 유지하는 동적 점 제약으로 토크·관성·중력에 따른 회전을 계산한다. 머리 질량은 12, 몸통은 4.5로 머리를 가장 무거운 단일 부위로 정했다. 회전 방향은 전체 질량중심과 접촉·관절 힘에 따른다.
- 고속 잡기 이동도 하위 스텝으로 나눠 한 프레임 안에 목표 포인터까지 연결점을 옮긴다. 놓을 때 포인터 속도의 50%를 전 부위에 전달하며 기존 각속도는 유지한다.
- 각운동을 강화했다. 기본 회전 관성을 기존의 65%로 낮추고, 관절 감쇠는 0.05 → 0.025, 각속도 상한은 0.35 → 0.7 rad/60Hz 기준 스텝으로 조정했다. 질량·선속도·추가 지연값은 유지한다. 물리 세분화에 회전에 따른 가장자리 이동량도 포함한다.
- 웹페이지 실험 노트에 각운동 설명과 적용값(회전 관성 65%, 관절 감쇠 0.025, 각속도 상한 42rad/s)을 표시한다. 표시값은 물리 설정 상수에서 가져오며 각속도는 초 단위로 변환한다.
- 이번 조정의 타입 검사·빌드·테스트 및 실제 조작 확인은 실행하지 않았다.

## 3. 채택한 2번 방식의 실행 순서

1. 시작 시 기립 상태이며 신체 간 충돌이 켜져 있다.
2. 잡는 동안 모든 부위가 동적 상태이며 클릭 지점에 점 제약을 연결한다. 잡은 부위도 중력·관절 힘에 따라 회전한다. 물리 계산 뒤 남은 연결점의 위치 오차만 보정한다.
3. 놓으면 점 제약을 제거하고 던지기 벡터를 전달하며 각속도를 유지한다. 자기 충돌은 계속 켜져 있다.
4. 조작 종료 후 `repairSeconds`만큼 게임 시간이 지나면 관절 정렬을 시작한다. N은 **2초 고정**이다.
5. 정렬은 약 **0.6초** 동안 진행한다. 몸통의 현재 위치·방향을 매 스텝 기준으로 삼고, 다른 부위의 상대 각도와 연결 위치 오차를 줄인다.
6. 각 보정 스텝 전의 신체별 선속도·각속도를 저장한 뒤 보정 후 복원한다. 몸통을 시작점으로 옮기거나 정렬을 위해 전체 속도를 지우는 처리는 하지 않는다.
7. 정렬 완료 후 자유 물리 상태로 돌아온다. 새 조작이 들어오면 이전 정렬을 취소하고 2초 타이머를 다시 시작한다.
8. 이후 기존 안정 조건 또는 최대 부위 선속력 50px/s 이하가 2초 이어지면 현재 위치에서 일어난다.

현재 타이머는 **조작 종료 이후**를 기준으로 한다. 계속 잡고 있는 동안에는 타이머가 재시작되며, 같은 조작에 대해 정렬을 반복 실행하지 않는다. 일시정지 중에는 타이머와 모션이 진행되지 않는다.

### 정렬 시 보존하는 것과 바뀌는 것

- 몸통의 현재 위치·방향을 정렬 보정의 기준으로 유지한다. 움직이는 몸통을 매 스텝 따라가며 기준점을 갱신한다.
- 정렬 보정 전의 각 부위 월드 좌표계 선속도·각속도를 복원하도록 작성했다. 중력·마찰·실제 충돌에 의한 물리 변화는 계속 적용된다.
- 관절을 펴기 위해 팔다리의 각도와 중심 좌표는 바뀐다. 모든 부위의 좌표를 고정한 채 각도만 바꾼다는 뜻은 아니다.
- 정렬 중 관절의 강성·감쇠를 잠시 해제하고, 완료·취소 시 원래 값으로 복원한다. 신체 전체를 정적으로 바꾸지 않는다.
- 겹침·방 경계 보정은 몸통을 이동 대상에서 제외하고 다른 부위에 적용한다. 보정 캐시를 비우되 힘·이동 벡터 자체를 초기화하지 않는다.

이 내용은 현재 코드의 처리 방식이며, 모든 상황에서의 운동 보존·비겹침이 검증됐다는 의미는 아니다.

## 4. 자동 기립과 정지 판단

| 항목 | 현재 코드 기준 |
| --- | --- |
| 관절 정렬과의 순서 | 조작 종료 2초 뒤 관절 정렬을 먼저 실행하고, 완료 후 기립 조건 판단 진행 |
| 이동 관찰 | 각 부위의 실제 이동 거리 + 회전에 따른 가장자리 이동 |
| 짧은 접촉 흔들림 | 200ms 평활화 적용 |
| 기립 허용 조건 | 무입력 700ms 이후 `(기존 안정 조건) OR (모든 부위의 선속력 ≤ 50px/s)` |
| 기존 안정 조건 | 회전 포함 평활화 속력 12px/s 미만 + 바닥 접촉（중력 0이면 접촉 생략） |
| 새 속력 조건 | 부위별 중심의 선속력 중 최댓값 사용. 회전 속력·바닥 접촉을 요구하지 않음 |
| 기립 대기 | 고정 2초. 초기 300ms 조건 확인도 이 2초에 포함 |
| 대기 중 동작 | 물리 계속 계산. 신체 전체 고정·속도 초기화 없음 |
| 움직임 재개 | 두 조건을 모두 벗어나면 대기 취소. 새 선속력 조건이 참이면 기존 회전 판정만으로 취소하지 않음 |
| 실제 기립 | 준비 정렬 약 0.8초 + 일어나는 모션 약 1.5초 |

시작·기립 완료 상태와 실제 기립 모션은 정적 자세 제어를 사용한다. 이동 중 관절 정렬 및 기립 대기에서 물리가 계속 진행되는 것과 구분한다.

## 5. 최종 확정 수치와 조작

| 항목 | 최종값 / 동작 | 코드 기준 |
| --- | --- | --- |
| 관절 복구 방식 | 2번 채택 / 선택 메뉴 제거, 1번은 내부 비교용 | `experiment` |
| 관절 정렬 대기 | 2초 고정 / 조절 바 제거 | `repairSeconds` |
| 중력 | 2.5× 고정 / 조절 바 제거 | `gravity` |
| 탄성 | 95% 고정 / 조절 바 제거 | `bounce` |
| 던지기 강도 | 50% 고정 / 조절 바 제거 | `throwScale` |
| 관절 지연 | 0% 고정 / 조절 바 제거 | `lag` |
| 기립 대기 | 2초 고정 / 조절 바 제거 | `idleSeconds` |
| 새 기립 속력 조건 | 모든 부위의 중심 선속력 ≤ 50px/s / 기존 안정 조건과 OR | `STANDING_SPEED` |
| 관절 정렬 모션 | 약 600ms | `TORSO_ALIGNMENT_MS` |
| 회전 관성 | 기본 형상 관성의 65% / 질량과 별도로 적용 | `ANGULAR_INERTIA_SCALE` |
| 관절 감쇠 | 0.025 | `JOINT_DAMPING` |
| 각속도 상한 | 42rad/s = 60Hz 기준 스텝당 0.7rad | `MAX_ANGULAR_SPEED` |
| 머리·몸통 질량 | 머리 12 / 몸통 4.5, 머리가 가장 무거운 단일 부위 | `Ragdoll` 신체 생성부 |
| 물리 계산 | 기본 120Hz / 고속 이동·회전은 최대 64개 하위 스텝 | `FIXED_STEP`, `MAX_SUBSTEPS` |
| 관절·물리 표시 | OFF / ON | `debug` |

웹페이지의 **실험 노트**는 탄성·던지기 강도·중력·관절 정렬 대기·관절 지연·기립 대기를 읽기 전용으로 표시한다. 별도 **각운동** 항목에는 클릭 지점을 축으로 회전하는 원리와 회전 관성 65%·관절 감쇠 0.025·각속도 상한 42rad/s를 표시한다. 각운동 표시값은 물리 설정 상수에서 가져와 코드와 화면의 값이 일치하도록 구성했다. 물리 수치의 조절 바와 복구 방식 선택 메뉴는 없으며, 관절·물리 표시만 켜고 끌 수 있다.

단축키는 `R` 재배치, `Space` 일시정지/재개이다. 잡기·던지기는 마우스로 직접 조작한다. 입력 요소나 버튼에 포커스가 있으면 해당 요소의 기본 키 동작을 우선한다. 재배치는 설정과 일시정지 여부를 유지한다. 설정·진행의 영구 저장은 아직 없다.

## 6. 물리·입력 안정화의 진행 이력

| 문제·요구 | 반영한 변경 |
| --- | --- |
| 초기 상태가 쓰러진 인형 | 기본 기립 및 조작 후 현재 위치 기립 추가 |
| 얼굴·신체가 늘어나는 표현 | 얼굴 워핑을 우선 범위에서 제외. 회전 관성·추종 지연을 사용 |
| 빠르게 잡아 움직일 때 멈춤 | 관절 거리 12px/95px 초과에 따른 위치 복원·재배치 제거, 직접 포인터 추종 적용 |
| 놓아도 마우스 속도만큼 날아가지 않음 | 선속도 24 상한 제거, 마지막 실제 입력 구간 계산, 모든 부위에 동일한 던지기 벡터 전달 |
| 던지기 힘이 지나치게 큼 | 별도 배율 추가, 기본 35%로 조절 |
| 병합 이벤트 때문에 놓는 속도가 0이 됨 | 실제 입력 시각·병합 샘플 처리, 중복 위치 이벤트로 마지막 이동을 덮어쓰지 않도록 보완 |
| 멈춘 뒤 놓아도 예전 속도로 날아감 | 80ms 이상 지난 입력 벡터는 사용하지 않음 |
| 바닥에서 접촉 진동 | 위치와 접촉 방향 속도를 함께 보정, 추가 분리 간격 0.35px → 0.001px |
| 중심이 제자리라는 이유로 회전 중 강제 정지 | 부위별 실제 이동·회전 관찰, 기립 대기를 동적 상태로 변경 |
| 충돌 보정 실패 시 같은 자세가 반복됨 | 현재 위치에서 최대 512회 추가 보정한 뒤에만 안전 자세 복원 검토 |
| 관절 복구가 사실상 기립 준비와 같음 | 이동 중 정렬과 정지 후 기립을 분리, 두 방식 비교 후 2번 채택 |
| 바깥으로 빼는 연출이 의도와 다름 | 별도의 외측 이동 경로 제거, 연결점·몸통 기준 보정으로 변경 |

물리는 120Hz 기준이며 렌더링과 분리한다. 고속 자유 비행과 잡기 이동은 최대 64개 하위 스텝으로 나누고 정상 범위에서 스텝당 이동을 약 6px 이하로 줄인다. 선속도 상한은 없으며, 각속도 제한은 0.7 rad/60Hz 기준 스텝이다. 세분화에는 회전에 따른 가장자리 이동도 포함한다. 겹침 해소 실패에 대한 안전 자세 복원과 방 이탈·비정상 숫자의 예외 재배치는 관절 거리 오차 롤백과 별개이다.

## 8. 검증 이력과 현재 확인 범위

| 구분 | 기록 |
| --- | --- |
| 실험 1까지의 과거 자동 검증 | 당시 Chromium 시나리오 25개·타입 검사·정적 빌드 통과 기록 있음 |
| 실험 2 추가 이후 | 사용자 요청에 따라 에이전트가 타입 검사·빌드·테스트를 실행하지 않음 |
| 사용자 선택 | 2026-11-08에 2번을 개발 기준으로 채택 |
| 1단계 설계 완료 | 사용자 결정으로 현재 구현·확정 수치를 기준으로 마무리. 소스·기존 문서 확인 및 문서 정리만 진행 |

**과거 25개 통과 기록을 현재 2번 버전의 검증 결과로 간주하지 않는다.** 사용자 측 검사 결과는 이 문서 작성 시점에 별도로 전달받지 않았다.

기존 테스트에는 1번의 놓은 뒤 자기 충돌 OFF, 이전 국소 복구 조건, 이전 설정 객체를 전제로 한 검사가 포함되어 있다. 2번을 검증하려면 모드를 명시하고 현재 설정·정렬 동작에 맞춰 기대값과 시나리오를 갱신해야 한다. 삭제한 밀치기·고정값 슬라이더·복구 방식 선택 메뉴, 기존 고정 각도 잡기, `configure()`에서 고정값을 바꾸는 검증도 현재 동작에 맞춰 수정이 필요하다. 테스트 파일은 이번에 수정하거나 실행하지 않았다. 현재 기본값이 2번인 상태에서 이전 테스트 결과를 그대로 비교하지 않는다.

## 9. 설계 완료 후 확인 사항과 후속 개발

기초 물리 엔진 설계 완료와 별도로, 아래 항목은 사용자 검증 또는 후속 기능을 결합할 때 확인할 사항으로 남긴다. 아래 목록은 새 물리 설계 작업의 착수나 에이전트의 검증 통과를 의미하지 않는다.

### 사용자 검증·후속 통합에서 확인할 사항

- 조작 종료 2초 전·후의 정렬 시작 시각, 조작별 1회 실행, 재조작·일시정지 시 취소·재시작.
- 공중 이동·회전 중 몸통 기준점과 정렬 보정 전후 선속도·각속도의 보존.
- 벽·바닥에 몰린 상태에서 몸통 위치 유지, 신체 비겹침, 관절 연결 거리의 동시 만족 여부.
- 충돌 보정이 수렴하지 않는 경우의 처리. 현재 `TorsoAlignment.step()`은 분리 함수의 성공 여부로 정렬 완료를 지연시키지 않으므로 해당 경계 상황을 별도로 확인해야 한다.
- 정렬 중 복원하는 속도와 이후 중력·충돌·각속도 제한의 영향을 구분해 평가.
- 기립 대기 중 강제 멈춤 재발 여부와 정렬 → 자유 물리 → 정지 대기 → 기립의 전체 흐름.
- 확정 수치(탄성 95%·중력 2.5배·던지기 50%·지연 0%·각 대기 2초)와 0.6초 정렬 시간에서의 조작감.
- 중심·가장자리·이미 회전한 부위 잡기에서 클릭 지점 유지, 질량중심에 따른 매달림, 놓을 때 각속도 유지.
- 고정 탄성 95%와 강화한 각운동에서 반복 충돌·관절 연결·비겹침·프레임 성능.
- 50px/s 경계의 포함 여부, 기립 대기의 취소·재시작, 기존 안정 조건과 OR 적용, 정렬 완료 후 2초 대기.
- 고속 이동·복잡한 접촉의 프레임 성능, 지원할 PC 브라우저, 실제 모바일 입력.

### 아직 구현하지 않은 기능

사진 선택·얼굴 검출·보정·머리 적용, 최종 캐릭터/배경 아트, 표정·멍·반창고 등 피격 변화, 정식 무기 3종, 음향·타격 연출, 점수·콤보·해금, 로컬 저장, 공개 배포는 후속 단계이다. 서버·계정·온라인 랭킹·사진 공유는 현재 범위에 포함하지 않는다.

다음 계획 단계는 **2단계 사진 적용의 조기 검증**이다. 얼굴 사진 표시가 머리의 위치·회전을 따라가도록 연결하고, 현재 물리 동작과 확정값을 개발 기준으로 유지한다. 이 문서 정리로 1단계 기초 물리 엔진 설계를 마무리하며, 다음 단계 구현은 별도 요청에서 진행한다.
