# 방 화면과 체력 조절 (2026-11-17)

> 과거 개발 기록입니다. 당시 미구현·예정·비교 실험·검증 수치는 현재 상태를 뜻하지 않습니다. 2026-11-18 사용자 결정으로 3·4단계를 완료했으며, 현재 기준은 [개발 계획](../../DEV_PLAN.md)과 [계산 규칙](../PHYSICS_AND_DAMAGE.md)을 따릅니다. 비교용 실험 1 코드는 정리 과정에서 제거했습니다.

상단 조작바와 방이 브라우저 안을 채운다. 오른쪽 실험 노트·설명·체력 목록·하단 안내를 제거했다. 상단에는 효과음 → 최대 데미지 조절, 오른쪽에는 인형 추가 → 강제 폭파 → 사진 추가/편집 → 일시정지 → 재배치를 배치했다. 기본 얼굴로 되돌리기는 사진 편집 창 안에서 제공한다.

## 화면 크기 기준

2026년 10월 [Statcounter 데스크톱 통계](https://gs.statcounter.com/screen-resolution-stats/desktop/worldwide)에서 1920×1080은 27.82%, 1536×864는 9.13%, 1366×768은 7.48%다. 같은 달 [Steam 조사](https://store.steampowered.com/hwsurvey/Steam-Hardware-Software-Survey-Welcome-to-Steam)에서는 1920×1080이 50.23%, 2560×1440이 21.82%다. 이는 평균 모니터의 물리적 대각선 길이가 아닌 해상도 분포다. 방은 특정 해상도로 고정하지 않고 실제 브라우저의 사용 가능한 영역을 따른다.

- 초기 화면은 창 안을 채운다. 1920×1080·1536×864·1366×768·390×844에서 조작바와 방이 페이지 스크롤 없이 표시되도록 한다.
- 방 높이는 사용자 설정의 800 게임 단위를 유지하고 폭은 실제 캔버스 비율에 맞춘다. 같은 비율의 화면에서는 인형과 벽 사이의 상대적인 거리가 유지된다. 화면을 늘려도 인형 모양을 가로나 세로로 찌그러뜨리지 않는다.
- 방의 실제 물리 벽·그리드·카메라·생성 위치·포인터 변환을 함께 갱신한다. 화면 크기 조절에서 체력·사진·인형을 초기화하지 않는다. 잡기는 던지기 없이 해제한다.
- 오른쪽 아래 모서리를 드래그해 방 화면을 줄이거나 늘린다. 창 밖으로 커지지 않으며 데스크톱 최소 프레임은 620×360이다. 좁은 창에서는 창 크기를 상한으로 삼는다.
- 모서리를 두 번 누르면 창에 맞춘다. 키보드로 모서리에 포커스한 뒤 방향키는 20px 단위 조절, Home은 창 맞춤이다. 크기는 새로고침 시 창 맞춤으로 돌아간다.
- 사진 편집 미리보기는 창·캔버스 크기가 바뀐 뒤 실제 머리 표시 크기에 다시 맞춘다.

## 데미지와 회복

- 상단 최대 데미지는 0~180, 기본 180이다. 속도·출처·잔해 보정으로 계산한 원래 피해량을 보존하고, 실제 HP 차감만 설정값 이하로 제한한다. 모든 인형과 피격 출처에 적용한다.
- 0은 HP 차감을 막는다. 속도 계산식과 사운드의 속도 조건은 유지하며 피격 무적시간을 새로 시작하지 않는다. 재배치 후에도 설정값은 유지한다.
- 강제 폭파 버튼/B는 선택한 살아 있는 인형의 HP를 즉시 0으로 만든다. 데미지 상한·피격 무적·생성 보호와 관계없이 기존 관절 분리·즉시 교체·잔해 5초 유지를 실행하며 각 부위의 속도를 유지한다. 일시정지·사진 편집 중이나 입력 요소 편집 중에는 B 단축키를 실행하지 않으며 키를 계속 누르는 자동 반복도 무시한다.
- 살아 있는 인형은 각 생명의 게임 시간 기준으로 매 1,000ms마다 HP 100을 회복한다. 최대 HP 1,000을 넘지 않으며 죽은 인형·잔해는 회복하거나 살아나지 않는다.
- 일시정지·창 비활성화·사진 편집 중에는 회복 시간이 흐르지 않는다. 렌더링 FPS와 무관하도록 고정 물리 시간과 회복 주기의 소수점 경계를 처리한다.
- 회복은 기존 자국을 지우지 않는다. 실제 HP 손실의 누적값을 따로 보관해 회복 후 다시 맞아도 40 손실마다 새 자국이 생긴다. 사진 변형 단계는 현재 HP 손실률에 따라 회복한다.

## 머리 위 체력바

상단 체력 영역과 숫자 인형 이름표를 제거했다. 각 살아 있는 인형의 머리 위에 HP 비율을 표시한다. 기본 머리는 72 게임 단위, 사진을 적용한 경우 실제 사진 크기만큼 바를 표시한다. 사진 회전 시에도 머리보다 위에 두며 방의 위쪽·옆쪽 경계를 넘지 않도록 위치를 제한한다. 잔해에는 체력바를 표시하지 않는다.
