# 물리·피해 계산 규칙

2026-11-18 현재 코드 기준입니다. 사용자 설정값은 `public/config/*.json`, 물리 고정값은 `src/game/config.ts`, 체력·충돌 기본값은 `src/game/damageConfig.ts`에서 관리합니다. 아래는 기존 동작을 정리한 것으로 5단계 점수식을 정의하지 않습니다.

## 시간과 속도

월드의 기본 스텝은 `1000/120 ms`, Matter 기준 스텝은 `1000/60 ms`입니다. 한 렌더 프레임에서 최대 50ms를 누적하며, 가장 빠른 부위의 선속도+회전 가장자리 이동과 포인터/무기 이동을 기준으로 스텝을 최대 64개로 세분화합니다. 목표 이동은 하위 스텝당 6px 이하이며 64개 한계에서는 이를 초과할 수 있습니다.

`beforeSolve`에서 Matter 속도는 현재 하위 스텝의 변위이므로 `1000 / body.deltaTime`을 곱해 px/s와 rad/s로 변환합니다. 충돌 처리 후 속도는 60Hz로 정규화되어 있으므로 `1000 / REFERENCE_STEP`을 곱합니다. `ContactMotion.captureMotion()`의 두 호출 시점을 구분합니다. 정적인 기립·낙하 포즈는 속도 0을 사용합니다.

접촉점 p, 중심 c, 중심 선속도 v, 각속도 ω에 대해:

```text
v_point.x = v.x - ω × (p.y - c.y)
v_point.y = v.y + ω × (p.x - c.x)
v_relative = v_point_own - v_point_peer
```

`ContactMotion.contactVelocity()`와 `relativeContactVelocity()`가 공통 구현입니다. 벽은 상대 속도 0입니다. 피해는 충돌 전 접근 속도, 사운드는 충돌 직후 상대 속력의 크기를 사용합니다. 자세 정렬·겹침 보정·잔해 제한으로 만든 이동을 타격 속도로 다시 측정하지 않습니다.

## 방·신체 충돌 피해

접촉 법선은 수집 시 대상 신체 안쪽을 향합니다. 접근 속도 `s = max(0, -dot(v_relative, normal))`를 사용하며 스치는 접선 운동과 벌어지는 접촉은 피해를 주지 않습니다.

```text
s ≤ 800 또는 유효하지 않은 입력: 0
raw = 20 × ((s - 800) × (s + 800)) / (1400² - 800²)
raw *= 부위 배율 × 표면 배율
```

기본 부위·표면 배율은 1이며, 잔해가 살아 있는 인형을 때리면 0.15를 곱합니다. 기준 속도 1400px/s에서 피해 20입니다. `(s-800)(s+800)`은 `s²-800²`과 같은 식입니다.

## 근접 무기와 탄알

```text
무효 속도, speed < minSpeed, speed ≤ 0: 0
ratio = clamp(손잡이에서 타격점까지의 비율, 0, 1)
weight = handleMultiplier + (tipMultiplier - handleMultiplier) × ratio
raw = amount × (speed / referenceSpeed)^speedExponent × weight
```

방망이는 접촉 상대 속력의 크기, 망치는 머리가 표면으로 접근하는 법선 속도를 사용합니다. 잡은 무기의 구속 후 이동은 실제 변위·회전에서 속도를 계산합니다. 망치 손잡이는 공격 영역에서 제외합니다. 사진 윤곽과 기본 도형 모두 같은 접촉·타격 간격 판정을 사용합니다.

탄알은 `projectile.damage`의 고정 피해를 사용합니다. 비행 궤적의 연속 충돌로 가장 먼저 맞은 부위/벽을 찾고 명중한 탄알을 한 번만 소비합니다. 탄알은 기존 300ms 무적을 무시하며 새 무적을 만들거나 연장하지 않습니다.

## 상한과 실제 손실

1. 화면 값이 0 이상이면 모든 타격에 그 값을 상한으로 사용합니다. 0은 피해 없음입니다.
2. 화면 값이 -1이면 JSON의 무기별·벽 면별·생체·잔해별 상한을 사용합니다.
3. JSON 상한도 -1이면 무제한입니다. 부동소수 오버플로는 유한 최댓값으로 제한합니다.

`damageLimit()`에서 상한을 선택하고 원래 식·잔해 배율 계산 후 `capDamage()`를 적용합니다. 화면 상한을 선택하기 전에 JSON 상한으로 피해를 자르지 않습니다. 실제 손실은 `min(현재 HP, 계산 피해)`이며 상처와 숫자는 실제 손실을 사용합니다. 타격 강도 분류는 무적·남은 HP 차감 전 계산 피해 기준입니다.

같은 하위 스텝의 접촉은 선택된 상한을 적용한 피해 내림차순으로 처리합니다. 신체 부위·상대별 접촉 회차를 유지하고, 피해는 두 번 이상 분리된 스텝이면서 20ms 이상 떨어진 뒤 재허용합니다. 사운드는 실제 접촉 분리만으로 재허용합니다. 접촉 회차와 무적은 서로 다른 중복 방지 장치입니다.

`DamageSystem`은 생명 ID·출처별 단조 증가 hit ID·시간·부위·좌표를 확인합니다. 충돌·근접 타격의 실제 손실 후 300ms 무적이 시작됩니다. 약한 접촉이나 피해 0은 무적을 시작하지 않습니다. 생성·착지 보호도 검사합니다. 오래된 생명·중복 타격·이미 죽은 대상에는 피해를 주지 않습니다.

## 체력·상처·교체

- HP는 1,000이며 살아 있는 동안 게임 시간 1초마다 100 회복합니다. 초과 회복과 사망 후 회복은 없습니다.
- `totalDamage`는 생명 동안의 실제 HP 손실 누적입니다. 회복해도 줄이지 않고 누적 40마다 상처를 추가합니다. 표시 상처는 최대 100개입니다.
- 사진 단계는 누적 손상이 아닌 현재 손실률 `(maxHp - hp) / maxHp`로 결정합니다. 30%부터 1단계, 65%부터 2단계이며 회복에 따라 낮아집니다.
- 사진 변경은 표시 자국만 초기화하며 HP와 이미 넘은 누적 임계값은 유지합니다. 안전 재배치는 HP·누적 임계값을 유지합니다.
- HP 0에서는 기존 부위 속도·회전을 유지해 관절을 분리하고 즉시 교체합니다. 잔해는 5초, 끝 300ms만 페이드합니다. 무기별 마지막 타격은 별도 수명 상태로 진행합니다.

## 몸통 정렬과 기립

살아 있는 인형은 잡기·놓기·정렬·기립 동안 자기 충돌을 유지합니다. 잔해만 자체 충돌을 끕니다. 조작 종료 2초 뒤 600ms 동안 현재 몸통 위치·각도를 기준으로 정렬합니다. 보정 전 선속도·각속도를 복원하고 관절 강성·감쇠는 정렬 종료·취소 때 원래 값으로 돌립니다.

정렬 후 회전을 포함한 관측 속력 12px/s 미만+접지(또는 중력 0) 조건, 또는 모든 부위의 중심 선속력 50px/s 이하 조건을 만족하면 2초 기립 대기를 시작합니다. 최초 300ms 확인도 포함합니다. 대기 중 물리를 계속 계산하고 안정 조건에서 벗어나면 취소합니다. 실제 기립만 포즈 제어를 사용합니다.

## 사운드

충돌 후 접촉점 상대 속력 `v`가 `[a,b)`에 있을 때 `sound-size: [c,d]` 배율은 `c + (d-c) × (v-a)/(b-a)`입니다. 범위 밖은 무음입니다. 벽·천장·바닥은 일반음+벽음, 신체·잔해는 일반음만 사용합니다. 피해의 충돌 전 속도 임계값·무적은 음량과 독립적입니다.

일시정지는 물리·회복·피해 무적·상처·이펙트·잔해·콤보 확장용 게임 시간 모두를 멈추는 기준입니다. 콤보 자체는 아직 구현하지 않았습니다. 사운드 필드·쿨다운·동시 재생 상한은 [사운드 안내](../public/config/SOUNDS.md)를 따릅니다.
