# 5단계 착수 전 정리

2026-11-18. 사용자 결정에 따라 3단계 무기·타격감과 4단계 캐릭터·누적 변화를 완료 상태로 반영했습니다. 5단계 점수·콤보·해금은 구현하지 않았으며 Sites 배포도 실행하지 않았습니다.

## 변경

- README·개발 계획·게임 규칙·프로젝트 구조를 현재 구현 기준으로 정리했습니다. 오래된 ‘무기 미구현’·‘4단계 예정’과 서로 다른 테스트 집계를 제거했습니다.
- 이전 기획·단계 보고서·화면 보고서 7개를 `docs/archive/`에 옮기고 당시 기록임을 표시했습니다. 내부 문서 링크를 새 위치에 맞췄습니다.
- 비교용 실험 1, `JointRepair`, 항상 0으로 고정된 관절 지연 모터, 사용하지 않는 `startAirborne`, 불필요한 import를 제거했습니다. 현재 채택된 몸통 정렬·자기 충돌·기립 경로를 유지했습니다.
- `ContactMotion`에 충돌 전/후 단위 변환과 회전 접촉점 속도식을 모았습니다. 월드 좌표만 있는 사운드 접촉을 회전된 신체에서 다시 회전하던 오류를 수정했습니다.
- 피해 상한을 `capDamage`에 모아 방 충돌·근접·탄알 경로에서 같은 규칙을 사용합니다. 상한 우선순위·수치·무적·탄알 개별 피해는 유지하고 NaN과 음수 입력 처리를 정리했습니다.
- 사진 윤곽과 기본 무기의 근접 타격 간격 처리를 합치고, 인형·복합 무기 삭제 시 Matter 접촉 캐시 정리를 공통화했습니다.
- 기본 사망 사운드의 존재하지 않는 OGG 2개를 실제 포함된 `BOOM.mp3`로 교체했습니다. 사용자 JSON·음원 파일·이미지 파일은 수정하지 않았습니다.
- 타입 검사에 사용하지 않는 변수·인자 검사를 추가하고 Vite 설정의 확장자 누락 경고를 해결했습니다.
- 과거 UI·실험 1을 기대하던 물리 테스트를 현재 규칙으로 교체했습니다. 정렬 시간·취소·몸통/운동 보존·기립·던지기·캡처 해제·화면 크기·반복 초기화·고속 경계·접촉점 수학을 검증합니다.
- `test:current`를 전체 검사로 통일하고 `test:physics`, `test:sound`를 추가했습니다. 계산 기준은 [물리·피해 규칙](PHYSICS_AND_DAMAGE.md)에 모았습니다.

## 검증

검증 환경: Node.js 22.23.1 / npm 12.1.0, Playwright Chromium.

| 검사 | 결과 |
| --- | --- |
| `npm run check` | 타입·미사용 변수/인자 검사 통과 |
| `npm run build` | 정적 빌드 통과. 기존 큰 청크 경고는 유지 |
| `npm test` | **199개 전체 통과** |
| 빌드 결과 Chromium 검사 | 게임·무기 생성·사진 목록·실제 얼굴 분석·사진 적용 통과 |
| 모델·WASM·JSON·사진 | 로컬 정적 호스트에서 정상 응답, 실제 얼굴 검출 성공 |
| 정적 페이지의 개발 기능 | 로컬 저장 버튼·진단 전역 객체 없음 |
| 런타임 요청 | 확인 중 외부 호스트 요청·실패 응답·페이지 오류 없음 |
| 문서 링크·공백 | Markdown 파일 링크 검사·`git diff --check` 통과 |
| 사용자 자산 | 무기·이펙트·사운드 JSON, 음원·이미지, lockfile 변경 없음 |

최종 전체 실행은 수정이 끝난 소스와 테스트를 기준으로 수행했습니다. 과거 실험/UI의 기대값을 현재 규칙으로 교체했으며, 초기 실행에서 확인한 사운드 파일 수 차이와 MP3 실패 모의 설정도 최종 검사에 반영했습니다.

Sites 원격 배포와 다른 브라우저·모바일 검증은 수행하지 않았습니다. 큰 JS 청크와 WASM 용량은 공개 전 성능 확인 항목으로 남깁니다.

Sites 관련 근거와 원격 검증 한계는 [배포 가능성 확인](SITES_FEASIBILITY.md)을 참고합니다.
