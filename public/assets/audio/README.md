# 충돌 효과음

현재 `sfx/kenney_impact-sounds/`의 Kenney Impact Sounds 1.0을 사용한다. 원본 파일명과 `License.txt`를 유지한다. CC0이며 출처는 https://kenney.nl/assets/impact-sounds 이다.

## 사용자 설정 위치

사용자가 직접 `public/assets/audio/sounds.json`을 작성한다. 애플리케이션은 이 파일을 생성하거나 수정하지 않는다. 저장 후 페이지를 새로고침하면 읽는다. 설정은 다운로드 캐시를 우회해 갱신한다.

JSON이 없으면 `src/audio/SoundConfig.ts`의 기본값으로 실행한다. 기본값은 약한 충돌 `impactGeneric_light_000~002`, 중간 충돌 `impactPunch_medium_000~002`, 강한 충돌 `impactPunch_heavy_000~002`, 분리 `impactSoft_heavy_000~001`의 11개 OGG 파일이다. ZIP과 나머지 음원은 런타임에서 요청하지 않는다.

## 앞서 합의한 JSON 형식

| 필드 | 규칙 |
| --- | --- |
| `version` | `1` |
| `basePath` | 앱 배포 경로 기준 상대 디렉터리. 기본값을 쓸 때는 `assets/audio/`. `public/`이나 맨 앞 `/`는 넣지 않는다 |
| `masterVolume` | 전체 배율 0~1, 생략 시 0.8 |
| `maxConcurrentSounds` | 전체 동시 재생 상한, 정수 1~32. 생략 시 8 |
| `defaults` | 이벤트의 기본 `volume`, `rateRange`, `cooldownMs`, `maxVoices`, `priority`. 이벤트 필드가 우선 |
| `events` | 이벤트 이름을 키로 하는 객체. 충돌은 `collision.*`, 사망 분리는 `death.burst` |
| `events.*.files` | 비어 있지 않은 상대 음원 경로 목록. `basePath` 뒤에 붙이며 같은 파일은 한 번만 디코딩한다 |
| `events.collision.*.speedRange` | `[최솟값, 최댓값]`. px/s, 최솟값 포함·최댓값 제외. 최댓값 `null`은 상한 없음. 범위 중복은 오류, 빈 구간은 무음 |
| `volume` | 이벤트 음량 0~1, 생략 시 0.6 |
| `rateRange` | 두 재생 속도 배율. 각각 0.25~4, 작은 값부터. 기본 `[0.96, 1.04]`. 음높이도 함께 변한다 |
| `cooldownMs` | 같은 인형·이벤트의 최소 간격 0~60000ms, 기본 80. 일시정지 중에는 시간이 흐르지 않는다 |
| `maxVoices` | 이벤트 전체 동시 재생 상한, 정수 1~32. 기본 2 |
| `priority` | 정수 0~100, 기본 1. 큰 값이 우선. 전체 상한에 걸리면 더 낮은 우선순위 소리를 중단하며, 같은 우선순위는 추가하지 않는다 |
| `debris.volumeScale` | 잔해가 포함된 충돌의 음량 배율 0~1, 기본 0.35. 사망 분리음에는 적용하지 않는다 |

현재 실제 경로는 `sfx/kenney_impact-sounds/원본파일명.ogg`이다. 앞서 제안했던 `kenney-impact`와 다르므로 업로드한 디렉터리 이름을 사용한다. 다른 사운드 팩도 해당 폴더 안에 배치하고 `files`를 바꿔 사용할 수 있다. 충돌 이벤트 이름의 접미사는 바꿔도 속도 범위로 선택한다. 새로운 무기 이벤트는 게임에서 발생시키는 연결이 별도로 필요하다.

숫자·범위·목록·버전 오류가 있으면 기본 설정으로 실행하고 개발자 콘솔에 원인을 표시한다. 개별 음원을 불러오지 못하면 나머지 후보로 진행하며, 전체 음원이 없으면 게임을 소리 없이 계속한다. Web Audio를 쓸 수 없는 환경도 소리 없이 진행한다.

## 재생과 설정

- 선택한 음원만 시작 시 비동기로 내려받아 재생 가능한 오디오 버퍼로 보관한다. 기존 Phaser의 AudioContext를 공유하며 인형마다 버퍼나 AudioContext를 만들지 않는다.
- 첫 클릭 또는 키 입력으로 오디오 재생을 활성화한다. 준비되기 전 충돌음은 나중에 몰아서 재생하지 않는다.
- HP 차감과 독립된 실제 접근 속도·접촉 회차를 사용한다. 지속 접촉과 자기 신체끼리의 접촉은 반복음을 만들지 않는다. 기립 낙하·외형 미리보기·좌표 보정만으로 소리를 내지 않는다.
- 같은 외부 신체 접촉을 양쪽 인형이 보고하거나 한 렌더 프레임에 여러 하위 스텝에서 보고해도 하나로 합친다. 우선순위가 높고 충돌이 강한 소리부터 재생한다.
- 후보가 여러 개면 직전 파일을 피해서 무작위로 선택하고 `rateRange` 안에서 재생 속도를 바꾼다.
- UI의 효과음 음량은 JSON 전체 음량에 추가로 곱한다. 효과음 음량·음소거만 `lee-damage:sound` 로컬 설정에 보관하며, 저장 실패는 게임을 막지 않는다.
- 일시정지·창 비활성화·사진 편집에서는 소리와 대기열을 정리한다. R은 재생·회차 상태를 비우되 버퍼와 사용자 음량 설정은 재사용한다. 잔해 만료는 해당 소유자의 재생 간격 기록을 정리한다.

## 검증

`npx playwright test tests/sound-rules.spec.ts tests/sound.spec.ts`

규칙 7개와 Chromium 브라우저 8개를 검증한다. 실제 OGG 디코딩·오디오 신호 출력, JSON 교체·누락·오류, 약한 접촉·무적 중 충돌, 잔해 충돌·조용한 기립 낙하, 지속 접촉, 동시 재생/우선순위, 음량·음소거 저장, 일시정지·사진 편집·R·장면 종료의 정리를 포함한다. 최종 음색과 음량 밸런스는 실제 플레이로 조율한다.
