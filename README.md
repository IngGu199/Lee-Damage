# Lee Damage — 사진 실험실

PC 브라우저용 슬랩스틱 게임의 **2단계 내부 사진 시제품(0.6.0)**입니다. Phaser 3.90 내장 Matter의 방·인형 위에 사진 선택·원형/직접 그린 윤곽 편집·얼굴 특징점 분석·변형 사진 교체·투명 상처 에셋을 연결했습니다. 오른쪽 **사진 적용**에서 시작합니다. 무기·점수·음향은 후속 단계입니다. 현재 구현·검증·남은 평가 항목은 [2단계 진행 기록](STAGE_2_PROGRESS.md)에 정리했습니다.

1단계 기초 물리 엔진 설계는 2026-11-08 사용자 결정으로 완료했습니다. **2번: 조작 종료 N초 뒤 몸통 기준 관절 정렬**과 확정 수치를 유지하며, 당시 기록은 [1단계 정리](STAGE_1_PROGRESS.md)에 보존했습니다. 플레이 중 얼굴 직접 늘이기는 포함하지 않습니다.

## 실행

Node.js 22.12 이상을 권장합니다. 2단계 검증 환경은 Node.js 22.23.1 / npm 12.1.0입니다. 타입 검사·빌드·사진 관련 Chromium 검사 23개를 통과했습니다. 기존 실험 1의 물리 테스트는 현재 기본값과 기대값이 다른 항목이 있어 이번에 실행·갱신하지 않았습니다.

```bash
npm ci
npm run dev
```

터미널에 표시된 주소(기본 `http://localhost:5173`)로 접속합니다. 처음 실행할 때만 의존성 설치가 필요합니다.

```bash
npm run check          # TypeScript 검사
npm run build          # 타입 검사 및 dist/ 정적 빌드
npm run preview        # 빌드 결과 미리 보기
npx playwright install chromium  # 브라우저 테스트 최초 준비
npm run test:photo    # 현재 사진 적용·외형 변화의 브라우저 검증
npm test              # 전체 테스트. 과거 물리 시나리오는 현재 기준에 맞춘 갱신 필요
```

입력 요소나 버튼에 포커스가 있으면 해당 요소의 기본 키 동작을 우선합니다. 단축키를 사용하려면 게임 화면 또는 빈 곳에 포커스를 둡니다. PC용이며 모바일 터치는 별도 검증하지 않았습니다.

직접 그린 윤곽은 사진에 연결되므로 확대·회전·반전에서도 함께 움직입니다. 윤곽 사진에서는 둥근 머리 바탕을 숨겨 잘라낸 모양만 표시하며 물리 충돌 모양은 기존 원형을 유지합니다. 재편집·재배치·변형 사진 교체에서도 윤곽을 유지합니다. 열린 선·교차한 선·너무 좁은 영역은 적용할 수 없습니다.

기본 상태는 기립이며 자기 충돌이 켜져 있습니다. 밀치기 기능은 제거했습니다. 채택한 2번에서는 놓은 뒤에도 신체 간·벽·바닥 충돌을 유지합니다. 조작 종료 후 2초가 지나면 속도·접지·꼬임 각도 조건 없이 몸통 기준으로 한 번 정렬합니다. 약 0.6초 동안 현재 몸통 위치·방향을 따라 팔다리의 각도·연결 위치를 보정하고, 보정 전의 선속도·각속도를 복원하도록 작성했습니다. 중력·실제 충돌은 계속 적용됩니다.

관절 정렬과 기립은 별도입니다. 정렬 완료 이후 기존 안정 조건 또는 최대 부위 선속력 50px/s 이하 조건이 2초 이어지면 현재 위치에서 일어납니다. 정렬·기립 도중 다시 조작하면 중단하고 타이머를 다시 시작합니다. 재배치는 설정과 일시정지를 유지하며 기립·자기 충돌 ON으로 초기화합니다.

내부 비교용 1번 코드는 놓은 뒤 자기 충돌을 끄고 기립 완료 후 다시 켜는 이전 방식이며 웹페이지에서는 선택할 수 없습니다. 두 방식의 기준·구현 위치·검증 이력은 [STAGE_1_PROGRESS.md](STAGE_1_PROGRESS.md)를 참고합니다.

## 기술 선택

TypeScript + Vite + HTML/CSS, Phaser 3.90.0의 단일 Matter 엔진을 사용합니다. 얼굴 분석은 `@mediapipe/tasks-vision` 1.2.2와 로컬 제공 모델을 사용합니다. 사진 선택 시 모델·WASM을 준비하며 모든 사진 처리는 브라우저 안에서 진행합니다. 별도 `matter-js` 패키지, 서버 API, 사진 업로드, 로컬 저장 기능은 없습니다. 모델·이미지·글꼴도 같은 호스트에서 제공합니다.

현재 사진 입력은 JPEG·PNG·WebP / 20MB·4천만 화소 이하이고 얼굴 출력은 투명도를 유지하는 512×512 Canvas 텍스처입니다. 머리의 인정된 충격 3회마다 변형 단계가 바뀌며 상처는 최대 100개이며 초과 시 오래된 것부터 교체합니다. 마스크·변형 강도·충격 기준·재배치 시 피격 초기화는 시제품의 조정 가능한 기본값입니다. 모델 출처는 [모델 설명](public/models/README.md)을 참고합니다.

상처는 속력 기준을 넘긴 충돌마다 맞은 부위의 전체 표면에서 균일한 무작위 위치에 생깁니다. 테두리 근처도 포함하며 자국의 중심만 표면 안에 두므로 이미지 일부는 밖으로 나올 수 있습니다. 사진 얼굴은 불투명 픽셀 전체에서 중심을 고르고, 사진 배율을 바꿔도 같은 사진 위치를 따라갑니다. 사진·자국 배율은 재배치해도 유지됩니다.

물리는 120Hz 기준이며 렌더링과 분리됩니다. 빠르게 날아갈 때는 물리 간격을 더 잘게 나눕니다. 잡은 부위에는 마우스 추종 속도 제한을 적용하지 않습니다. 잡은 지점을 매 물리 스텝의 최신 마우스 위치에 직접 맞추고, 다른 신체는 관절·관성으로 따라옵니다. 방 경계는 유지하며, 놓는 순간 마지막 입력 벡터에 던지기 강도를 곱해 몸 전체에 전달하며 선속도 상한은 적용하지 않습니다. 실제 충돌과 공기 저항은 이후 속도를 바꿉니다. 자기 충돌이 켜져 있을 때 연결된 신체를 포함한 모든 부위의 충돌을 계산하고 잔여 침투를 제거합니다. 꺼져 있을 때는 신체 간 충돌과 침투 보정을 모두 건너뛰며, 방 경계 보정은 계속 적용합니다. 관절 거리 오차로 이전 자세를 복원하거나 재배치하지 않습니다. 겹침을 해소하지 못한 경우만 이전 자세를 참고해 접촉을 재보정하며, 이때 잡힌 지점은 새 마우스 위치에 유지합니다. 이상 좌표·방 이탈은 자동 재배치하고 복구 횟수를 표시합니다. 정상 자동 기립은 재배치와 별개입니다. 이 방어 기능은 실제 조작 튜닝을 대신하지 않습니다.

잡은 부위도 동적 물체로 계산하며 각도를 고정하지 않습니다. 클릭 지점의 로컬 좌표를 회전에 맞춰 갱신하는 점 제약을 사용하고, 물리 계산 뒤 연결점의 위치 오차를 보정합니다. 머리 질량 12, 몸통 4.5로 머리가 가장 무거운 단일 부위이며, 실제 매달림 방향은 전체 질량중심과 관절·접촉에 따라 결정됩니다. 추가 관절 지연은 0%로 고정해 회전 추종 모터를 적용하지 않습니다. 회전 반응을 강화하기 위해 관성을 이전의 65%로 낮추고 관절 감쇠를 0.025로 줄였으며, 각속도 상한은 0.7 rad/60Hz 기준 스텝으로 높였습니다. 물리 계산 분할에는 회전하는 신체 가장자리의 이동도 포함합니다. 빠른 잡기 이동도 하위 스텝으로 나눠 프레임 끝에 목표 위치에 도달합니다.

공식 참고: [Phaser Matter](https://docs.phaser.io/phaser/concepts/physics/matter), [Vite](https://vite.dev/guide/).

## 무입력 상태의 안정화

채택한 2번의 `TorsoAlignment`는 조작 종료 후 N초 뒤 현재 몸통을 기준으로 관절을 정렬합니다. 정렬 보정에서 전체를 정적으로 바꾸거나 속도를 지우지 않습니다. 관절 강성·감쇠를 잠시 해제하고 정렬 완료·취소 시 복원합니다. 팔다리 위치는 정렬·겹침 해소를 위해 바뀔 수 있으며, 모든 부위의 좌표를 고정한다는 뜻은 아닙니다.

기립은 기존 안정 조건(회전 포함 속력 12px/s 미만 + 바닥 접촉) 또는 모든 부위의 중심 선속력 50px/s 이하 중 하나를 만족하면 2초를 기다립니다. 초기 300ms 확인도 이 대기에 포함합니다. 대기 중에도 물리를 계산하며 두 조건을 모두 벗어나면 취소합니다. 실제 기립 모션에 들어가기 전에는 몸 전체를 고정하거나 속도를 지우지 않습니다.

복잡한 접촉은 현재 결과에서 추가 보정해 직전 자세를 반복 복원하던 멈춤을 방지합니다. 다만 2번의 경계 접촉·운동 보존·비겹침은 사용자 검증 대상입니다. 과거 실험 1의 테스트 25개 통과 기록은 현재 2번의 검증 결과가 아닙니다.
