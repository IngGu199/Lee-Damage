# Lee Damage — 충돌 실험실

PC 브라우저용 슬랩스틱 게임의 **3단계 무기·체력·충돌·재등장 다중 랙돌 시제품(0.8.0)**입니다. 기존 사진 편집·윤곽·변형 기능 위에 HP·속도별 방 충돌 데미지·손상 누적 상처를 연결했습니다. T키로 최대 10개의 인형을 만들 수 있고 각 인형은 개별 HP를 가집니다. HP 0에서는 관절이 분리되는 즉시 새 인형이 낙하하며, 잔해는 5초 동안 남아 잡고 던지거나 다른 인형과 부딪힐 수 있습니다. 상단 **사진 추가**에서 얼굴을 바꿀 수 있습니다. Kenney 충돌음·관절 분리음과 음량·음소거 설정을 지원합니다. 기본 도형 야구방망이·망치·총과 무기별 마지막 타격·JSON 이펙트를 지원하며 [무기와 이펙트 안내](WEAPONS_AND_EFFECTS.md)를 참고합니다. 최종 이미지·무기 수치 조율·점수는 후속 작업입니다. 기반 규칙은 [3단계 기반 보고서](STAGE_3_FOUNDATION_REPORT.md)에 정리했습니다.

1단계 기초 물리 엔진 설계는 2026-11-08 사용자 결정으로 완료했습니다. **2번: 조작 종료 N초 뒤 몸통 기준 관절 정렬**과 확정 수치를 유지하며, 당시 기록은 [1단계 정리](STAGE_1_PROGRESS.md)에 보존했습니다. 플레이 중 얼굴 직접 늘이기는 포함하지 않습니다.

## 실행

Node.js 22.12 이상을 권장합니다. 2단계 검증 환경은 Node.js 22.23.1 / npm 12.1.0입니다. 현재 검증은 타입 검사·빌드·기반 24개·다중 랙돌 14개·사진 24개로 구성된 검사 62개, 사운드 34개, 화면·체력 조절·강제 폭파 11개, 무기 21개(총 128개)를 기준으로 합니다. 기존 실험 1의 물리 테스트는 현재 기본값과 기대값이 다른 항목이 있어 이번에 실행·갱신하지 않았습니다.

```bash
npm ci
npm run dev
```

터미널에 표시된 주소(기본 `http://localhost:5173`)로 접속합니다. 처음 실행할 때만 의존성 설치가 필요합니다.


## 조작

무기·탄알 속도·이펙트·사운드 JSON의 필드와 수정 예시는 [config 설정 설명서](public/config/README.md)에 정리했습니다. 총알 속도는 `public/config/weapons.json`의 `defaults.projectile.speed`를 따르며, `weapons.gun.projectile.speed`로 별도 지정할 수 있습니다.

입력 요소를 편집 중일 때는 단축키를 실행하지 않습니다. `T`·`B`는 버튼에 포커스가 있어도 작동하며, `R`·`Space`는 게임 화면 또는 빈 곳에 포커스를 둡니다. PC용이며 모바일 터치는 별도 검증하지 않았습니다.

직접 그린 윤곽은 사진에 연결되므로 확대·회전·반전에서도 함께 움직입니다. 윤곽 사진에서는 둥근 머리 바탕을 숨겨 잘라낸 모양만 표시하며 물리 충돌 모양은 기존 원형을 유지합니다. 재편집·재배치·변형 사진 교체에서도 윤곽을 유지합니다. 열린 선·교차한 선·너무 좁은 영역은 적용할 수 없습니다.

기본 상태는 기립이며 자기 충돌이 켜져 있습니다. 밀치기 기능은 제거했습니다. 채택한 2번에서는 놓은 뒤에도 신체 간·벽·바닥 충돌을 유지합니다. 조작 종료 후 2초가 지나면 속도·접지·꼬임 각도 조건 없이 몸통 기준으로 한 번 정렬합니다. 약 0.6초 동안 현재 몸통 위치·방향을 따라 팔다리의 각도·연결 위치를 보정하고, 보정 전의 선속도·각속도를 복원하도록 작성했습니다. 중력·실제 충돌은 계속 적용됩니다.

관절 정렬과 기립은 별도입니다. 정렬 완료 이후 기존 안정 조건 또는 최대 부위 선속력 50px/s 이하 조건이 2초 이어지면 현재 위치에서 일어납니다. 정렬·기립 도중 다시 조작하면 중단하고 타이머를 다시 시작합니다. 재배치는 설정과 일시정지를 유지하며 기립·자기 충돌 ON으로 초기화합니다.

내부 비교용 1번 코드는 놓은 뒤 자기 충돌을 끄고 기립 완료 후 다시 켜는 이전 방식이며 웹페이지에서는 선택할 수 없습니다. 두 방식의 기준·구현 위치·검증 이력은 [STAGE_1_PROGRESS.md](STAGE_1_PROGRESS.md)를 참고합니다.

## 기술 선택

TypeScript + Vite + HTML/CSS, Phaser 3.90.0의 단일 Matter 엔진을 사용합니다. 얼굴 분석은 `@mediapipe/tasks-vision` 1.2.2와 로컬 제공 모델을 사용합니다. 사진 선택 시 모델·WASM을 준비하며 모든 사진 처리는 브라우저 안에서 진행합니다. 별도 `matter-js` 패키지, 서버 API, 사진 업로드, 로컬 저장 기능은 없습니다. 모델·이미지·글꼴도 같은 호스트에서 제공합니다.

현재 사진 입력은 JPEG·PNG·WebP / 20MB·4천만 화소 이하이고 얼굴 출력은 투명도를 유지하는 512×512 Canvas 텍스처입니다. 입과 각 눈의 중심을 유지하며 양끝이 아래로 처집니다. 실제 HP 손실률 30%·65%에 변형 단계가 바뀝니다. 외형 미리보기에서만 기존 머리 3회·6회 순환을 유지합니다. 2026-11-09 사용자 확정에 따라 사진 2배·일그러짐 1.8배·멍/상처/반창고 각각 1.5배를 고정하고 상단·오른쪽 실험 노트는 제거했습니다. 상처는 최대 100개이며 초과 시 오래된 것부터 교체합니다. 최소 속도 800px/s·피격 후 0.3초 무적·사망 조각 5초 유지·기립 착지를 적용했습니다. HP 1,000·손실 40당 상처·즉시 새 랙돌 생성과 살아 있는 인형 최대 10개를 지원합니다. 새 생명은 방 안의 중앙 공중에서 기립 자세를 유지하며 내려오고, 첫 바닥 접촉 후 150ms 또는 생성 후 최대 1,500ms까지 낙하 손상을 보호합니다. 잡거나 외부 물체에 부딪히면 낙하 제어가 풀려 일반 물리로 반응합니다. 모델 출처는 [모델 설명](public/models/README.md)을 참고합니다.

상처는 실제 HP 손실이 40의 임계값을 넘을 때 맞은 부위의 전체 표면에서 균일한 무작위 위치에 생깁니다. 테두리 근처도 포함하며 자국의 중심만 표면 안에 두므로 이미지 일부는 밖으로 나올 수 있습니다. 사진 얼굴은 불투명 픽셀 전체에서 중심을 고르고, 머리의 이동·회전을 따라갑니다. 확정된 외형값은 재배치·재편집 후에도 유지됩니다.

물리는 120Hz 기준이며 렌더링과 분리됩니다. 빠르게 날아갈 때는 물리 간격을 더 잘게 나눕니다. 잡은 부위에는 마우스 추종 속도 제한을 적용하지 않습니다. 잡은 지점을 매 물리 스텝의 최신 마우스 위치에 직접 맞추고, 다른 신체는 관절·관성으로 따라옵니다. 방 경계는 유지하며, 놓는 순간 마지막 입력 벡터에 던지기 강도를 곱해 몸 전체에 전달하며 선속도 상한은 적용하지 않습니다. 실제 충돌과 공기 저항은 이후 속도를 바꿉니다. 자기 충돌이 켜져 있을 때 연결된 신체를 포함한 모든 부위의 충돌을 계산하고 잔여 침투를 제거합니다. 꺼져 있을 때는 신체 간 충돌과 침투 보정을 모두 건너뛰며, 방 경계 보정은 계속 적용합니다. 관절 거리 오차로 이전 자세를 복원하거나 재배치하지 않습니다. 겹침을 해소하지 못한 경우만 이전 자세를 참고해 접촉을 재보정하며, 이때 잡힌 지점은 새 마우스 위치에 유지합니다. 이상 좌표·방 이탈은 자동 재배치하고 복구 횟수를 표시합니다. 정상 자동 기립은 재배치와 별개입니다. 이 방어 기능은 실제 조작 튜닝을 대신하지 않습니다.

잡은 부위도 동적 물체로 계산하며 각도를 고정하지 않습니다. 클릭 지점의 로컬 좌표를 회전에 맞춰 갱신하는 점 제약을 사용하고, 물리 계산 뒤 연결점의 위치 오차를 보정합니다. 머리 질량 12, 몸통 4.5로 머리가 가장 무거운 단일 부위이며, 실제 매달림 방향은 전체 질량중심과 관절·접촉에 따라 결정됩니다. 추가 관절 지연은 0%로 고정해 회전 추종 모터를 적용하지 않습니다. 회전 반응을 강화하기 위해 관성을 이전의 65%로 낮추고 관절 감쇠를 0.025로 줄였으며, 각속도 상한은 0.7 rad/60Hz 기준 스텝으로 높였습니다. 물리 계산 분할에는 회전하는 신체 가장자리의 이동도 포함합니다. 빠른 잡기 이동도 하위 스텝으로 나눠 프레임 끝에 목표 위치에 도달합니다.

공식 참고: [Phaser Matter](https://docs.phaser.io/phaser/concepts/physics/matter), [Vite](https://vite.dev/guide/).

## 무입력 상태의 안정화

채택한 2번의 `TorsoAlignment`는 조작 종료 후 N초 뒤 현재 몸통을 기준으로 관절을 정렬합니다. 정렬 보정에서 전체를 정적으로 바꾸거나 속도를 지우지 않습니다. 관절 강성·감쇠를 잠시 해제하고 정렬 완료·취소 시 복원합니다. 팔다리 위치는 정렬·겹침 해소를 위해 바뀔 수 있으며, 모든 부위의 좌표를 고정한다는 뜻은 아닙니다.

기립은 기존 안정 조건(회전 포함 속력 12px/s 미만 + 바닥 접촉) 또는 모든 부위의 중심 선속력 50px/s 이하 중 하나를 만족하면 2초를 기다립니다. 초기 300ms 확인도 이 대기에 포함합니다. 대기 중에도 물리를 계산하며 두 조건을 모두 벗어나면 취소합니다. 실제 기립 모션에 들어가기 전에는 몸 전체를 고정하거나 속도를 지우지 않습니다.

복잡한 접촉은 현재 결과에서 추가 보정해 직전 자세를 반복 복원하던 멈춤을 방지합니다. 다만 2번의 경계 접촉·운동 보존·비겹침은 사용자 검증 대상입니다. 과거 실험 1의 테스트 25개 통과 기록은 현재 2번의 검증 결과가 아닙니다.


## 충돌 효과음

일반 타격음 `collision.normal`과 벽·바닥음 `collision.wall`을 사용합니다. 강·중·약 등급을 나누지 않고 충돌 처리 직후 접촉점의 상대 속력(px/s)을 측정합니다. 각 이벤트의 `speed: [최소, 최대]` 구간에서만 재생하며, 구간 내 위치를 `sound-size: [최소 배수, 최대 배수]`에 선형 대응해 음량을 정합니다. 벽·천장·바닥에서는 일반음과 벽음이 함께 재생되고 다른 랙돌·잔해에서는 일반음만 재생됩니다. HP의 충돌 전 800px/s 조건·300ms 무적은 소리와 별도로 유지됩니다.

충돌 이벤트에 설정 객체 배열을 넣으면 여러 속도 구간을 지원합니다. 기존 단일 객체 형식도 사용할 수 있습니다. 각 구간은 최솟값 포함·최댓값 제외이며 구간 중복은 오류, 빈 구간은 무음입니다. `cooldownMs`가 0이면 새 충돌마다, 양수면 해당 구간의 지정 간격(ms)을 지킵니다. 중복 접촉 보고는 합치고 두 소리와 각 구간의 범위·음량·쿨다운은 독립적입니다. 작성 예시는 [효과음 설정 문서](public/config/SOUNDS.md)를 참고합니다. 잔해 음량은 기본 35%이며 전체·구간 재생 상한에서는 기존 소리를 교체합니다. 첫 클릭/키 입력 후 소리가 활성화되고 음량·음소거는 새로고침 후 유지됩니다.

사용자는 `public/config/sounds.json`에서 파일·속도·음량 배수 등을 조절합니다. 2026-11-18 설정과 설명서를 config로 옮겼으며 사용자 JSON의 내용과 `public/assets/audio/`의 음원은 보존했습니다. `basePath`는 설정 파일이 아닌 배포 앱의 시작 경로를 기준으로 합니다. 런타임은 JSON을 생성·수정하지 않으며 JSON이 없으면 기본값으로 실행합니다. MP3·M4A도 지원합니다. 규칙과 계산 예시는 [효과음 안내](public/config/SOUNDS.md), 무기 타격음 추가 절차는 [무기 사운드 안내](public/config/SOUNDS.md#무기-타격-사운드-추가)를 참고합니다.
