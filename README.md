# Lee Damage — 물리 실험실

PC 브라우저용 슬랩스틱 게임의 **1단계 내부 물리 시제품**입니다. Phaser 3.90에 내장된 Matter로 방 1개, 도형 인형 1개를 구현합니다. 사진·무기·점수·음향은 후속 단계입니다. 2026-11-05 요청에 따라 몸 겹침 방지·기립 복귀·관절 지연을 구현했고, 얼굴 늘이기는 현재 우선 범위에서 제외했습니다.

## 실행

Node.js 22.12 이상을 권장합니다. 현재 검증 환경은 Node.js 22.23.1 / npm 12.1.0입니다.

```bash
npm ci
npm run dev
```

터미널에 표시된 주소(기본 `http://localhost:5173`)로 접속합니다. 처음 실행할 때만 의존성 설치가 필요합니다.

```bash
npm run check          # TypeScript 검사
npm run build          # 타입 검사 및 dist/ 정적 빌드
npm run preview        # 빌드 결과 미리 보기
npx playwright install chromium  # 브라우저 테스트 최초 준비
npm test              # 실제 브라우저 입력·물리 안정성 검증
```

## 조작

| 조작 | 동작 |
| --- | --- |
| 잡기 도구 / `1` | 클릭한 지점이 마우스 위치를 직접 추종. 놓으면 마지막 마우스 속도 벡터를 몸 전체에 전달 |
| 밀치기 도구 / `2` | 신체를 클릭하면 클릭한 쪽의 반대 방향과 위쪽으로 충격 |
| 재배치 / `R` | 신체·관절·속도를 초기화. 설정과 일시정지 상태는 유지 |
| `Space` / 일시정지 버튼 | 물리·입력 일시정지 또는 계속하기 |
| 창 전환 | 잡는 연결 해제 및 자동 일시정지. 계속하기로 수동 재개 |
| 중력·탄성·밀치는 힘 | 실시간 물리 실험용 조절 |
| 관절 지연 | 빠르게 흔들 때 회전 추종 지연과 관성을 조절. 기본 65% |
| 기립 대기 | 움직임이 잠잠해진 후 자동 기립까지의 시간. 기본 3초, 1~8초 조절 |
| 관절·물리 표시 | 관절 연결점·충돌 외곽·속도 방향 표시 |

입력 요소나 버튼에 포커스가 있으면 해당 요소의 기본 키 동작을 우선합니다. 단축키를 사용하려면 게임 화면 또는 빈 곳에 포커스를 둡니다. PC용이며 모바일 터치는 별도 검증하지 않았습니다.

기본 상태는 기립입니다. 잡거나 밀치면 즉시 물리 반응으로 전환합니다. 놓은 뒤 바닥에서 느려지면 몸통 방향을 유지하며 꼬인 관절을 먼저 풀고, 흔들리지 않는 정지 자세로 대기한 다음 현재 위치에서 기립합니다. 벽 옆에서는 몸이 벽 안으로 들어가지 않는 최소 공간만 확보합니다. 기립 중 다시 잡거나 공격하면 복귀를 중단합니다. 일시정지 중에는 대기 시간도 멈춥니다.

## 기술 선택

TypeScript + Vite + HTML/CSS, Phaser 3.90.0의 단일 Matter 엔진을 사용합니다. 기존 계획의 Phaser 3 API와의 호환성을 위해 3.90.0을 고정했습니다. 별도 `matter-js` 패키지, 서버 API, 사진 업로드, 로컬 저장 기능은 없습니다. 실행 중 외부 이미지나 글꼴도 요청하지 않습니다.

물리는 120Hz 기준이며 렌더링과 분리됩니다. 빠르게 날아갈 때는 물리 간격을 더 잘게 나눕니다. 잡은 부위에는 마우스 추종 속도 제한을 적용하지 않습니다. 잡은 지점을 매 물리 스텝의 최신 마우스 위치에 직접 맞추고, 다른 신체는 관절·관성으로 따라옵니다. 방 경계는 유지하며, 놓는 순간 마지막 입력의 방향·크기를 몸 전체에 전달하며 선속도 상한은 적용하지 않습니다. 실제 충돌과 공기 저항은 이후 속도를 바꿉니다. 연결된 신체를 포함한 모든 부위의 충돌을 계산하고 잔여 침투를 제거합니다. 관절 거리 오차로 이전 자세를 복원하거나 재배치하지 않습니다. 겹침을 해소하지 못한 경우만 이전 자세를 참고해 접촉을 재보정하며, 이때 잡힌 지점은 새 마우스 위치에 유지합니다. 이상 좌표·방 이탈은 자동 재배치하고 복구 횟수를 표시합니다. 정상 자동 기립은 재배치와 별개입니다. 이 방어 기능은 실제 조작 튜닝을 대신하지 않습니다.

공식 참고: [Phaser Matter](https://docs.phaser.io/phaser/concepts/physics/matter), [Vite](https://vite.dev/guide/).

## 무입력 상태의 안정화

관절 복귀 힘이 자기 충돌과 계속 싸우던 문제를 없애기 위해, 관절 복구와 기립은 충돌을 검사하는 자세 애니메이션으로 처리합니다. 바닥 위치를 보정할 때 속도도 보정하고, 복구 후 정지 자세에서는 물리 힘·접촉 캐시를 비워 계속 떨리는 일을 방지합니다. 빠른 비행은 강제로 정지시키지 않습니다. 기본 기립 대기 3초는 관절 복구가 끝난 정지 자세에서 셉니다.
