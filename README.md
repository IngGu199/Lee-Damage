# Lee Damage — 충돌 실험실

PC 브라우저용 슬랩스틱 게임입니다. **2026-11-18 사용자 결정으로 3단계(무기 3종·타격감)와 4단계(캐릭터·누적 외형 변화)를 완료했습니다. 다음은 5단계 점수·콤보·무기 해금입니다.** 이번 정리는 5단계 기능을 추가하지 않습니다.

TypeScript + Vite + Phaser의 단일 Matter 물리 월드를 사용합니다. 최대 10개의 인형, 방망이·망치·총, 개별 체력·사진 변형·상처, 사망 연출과 교체 낙하를 지원합니다. 사진 편집·얼굴 분석은 브라우저에서 처리하며 서버 API나 DB가 필요하지 않습니다.

## 실행과 검증

Node.js 22.12 이상에서 실행합니다.

```bash
npm ci
npm run dev            # 터미널의 로컬 주소로 접속
npm run check          # 타입·사용하지 않는 변수/인자 검사
npm run build          # 타입 검사 + dist/ 정적 사이트 생성
npm run preview        # 빌드 결과 확인
npx playwright install chromium  # 브라우저 테스트 최초 준비
npm test               # 현재 규칙의 전체 회귀 검사
```

기능별 검사는 `test:physics`, `test:foundation`, `test:multi`, `test:photo`, `test:sound`, `test:weapons`를 사용합니다. `test:current`는 전체 검사와 같습니다. 최신 검증 결과와 변경 범위는 [정리 보고서](docs/CLEANUP_REPORT.md)에 기록합니다.

## 조작

| 조작 | 동작 |
| --- | --- |
| 좌클릭·드래그·놓기 | 인형·잔해·무기의 클릭한 지점을 잡아 이동하고 던짐 |
| `1` / 손 | 손 도구 선택 |
| `2` / 방망이 | 방망이 추가. 잡은 동안 우클릭마다 15° 회전 |
| `3` / 망치 | 무거운 머리가 자유 회전하는 망치 추가 |
| `4` / 총 | 포인터 위치에 고정 총 추가. 좌클릭 시 모든 총이 포인터 방향으로 발사 |
| `X` / `C` | 집은 무기 하나 / 모든 무기·비행 중 탄알 삭제 |
| `T` / 인형 추가 | 살아 있는 인형 최대 10개까지 추가 |
| `B` / 강제 폭파 | 선택한 인형을 보호·무적과 관계없이 분리하고 교체 |
| `R` / 재배치 | 인형·잔해·무기·탄알·연출을 정리하고 기립 인형 1개로 복귀 |
| `Space` / 일시정지 | 물리·입력·게임 시간 정지 또는 재개. 창 전환 시 자동 일시정지 |
| 사진 추가·사진 편집 | 얼굴/무기/탄알 사진 선택, 윤곽·투명 배경 복원, 위치·확대·회전·반전 편집 |
| 최대 데미지 | `0`: 무적, `-1`: JSON 조건별 상한 사용, 양수: JSON보다 우선하는 타격당 상한 |
| 무기·탄알 크기 | 무기 10~300%, 탄알 10~1000%. 종류별로 기억하고 표시·충돌 크기를 함께 변경 |
| 화면 오른쪽 아래 모서리 | 드래그·방향키로 크기 조절. 두 번 클릭 또는 Home으로 창에 맞춤 |

입력 필드를 편집할 때 단축키를 막습니다. R·Space는 게임 화면 또는 빈 곳에 포커스를 둡니다. 일시정지·사진 편집 중에는 생성·공격·무기 삭제를 막습니다.

고정 물리값은 탄성 95%, 중력 2.5배, 던지기 50%, 정렬 대기 2초, 기립 대기 2초입니다. 놓은 뒤에도 자기 충돌을 유지하고 약 0.6초 동안 현재 몸통 기준으로 관절을 정렬합니다. 조작을 다시 시작하면 정렬·기립을 중단합니다.

인형은 HP 1,000으로 시작하고 생존 중 게임 시간 1초마다 100 회복합니다. 충돌·근접 타격에는 300ms 무적이 있으며 총알은 발마다 별도로 피해를 줍니다. HP 0에서 새 인형을 즉시 생성하고 기존 잔해는 5초간 남습니다. 실제 손실 누적 40당 상처를 추가하고 현재 HP 손실률 30%·65%에서 얼굴 변형 단계를 바꿉니다. 자세한 수식은 [계산 규칙](docs/PHYSICS_AND_DAMAGE.md)을 따릅니다.

사용자 사진은 재배치 때 유지하고 새로고침하면 해제합니다. 사진·윤곽을 영구 저장하지 않습니다. 효과음 음량·음소거만 브라우저에 저장하며 점수·콤보·해금 저장은 5단계 범위입니다.

## 사진·설정과 배포

- [무기와 이펙트](WEAPONS_AND_EFFECTS.md): 무기별 타격·사망 연출·설정·검증
- [사진 사용 안내](WEAPON_PHOTOS.md): 얼굴·무기 사진, 저장된 사진 목록, 선택적 로컬 저장 확장
- [JSON 설정](public/config/README.md), [사운드 설정](public/config/SOUNDS.md): 수치·효과·음원 변경
- [Sites 배포 가능성](docs/SITES_FEASIBILITY.md): 정적 배포 조건과 확인 범위. **사이트 생성·업로드·배포는 실행하지 않았습니다.**

`public/images`의 사진 목록은 개발 서버에서 읽고 정적 빌드에서는 `images/catalog.json`으로 생성합니다. 배포 후 목록에 파일을 추가하려면 다시 빌드합니다. 프로젝트 폴더에 쓰는 저장 버튼/API는 Git에서 제외한 `.local/image-save/` 확장에만 있으며 정적 배포에는 포함되지 않습니다. 확장 없이도 사진 선택·편집·적용은 가능합니다.
